# CinemaCart
CinemaCart is a full-stack movie ticket booking application developed as a four-person team project for COMP 380 (Introduction to Software Engineering) at California State University, Northridge (CSUN). The application allows users to browse and search for movies, watch trailers, select showtimes and seats, manage a shopping cart, and complete the booking process through an interactive interface. The project was built using Java, HTML, CSS, JavaScript, and Firebase, with a focus on object-oriented programming, collaborative software development, and real-world software engineering practices.
