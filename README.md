# CinemaCart
CinemaCart is a full-stack movie ticket booking application developed as a four-person team project for COMP 380 (Introduction to Software Engineering) at California State University, Northridge (CSUN). The application allows users to browse and search for movies, watch trailers, select showtimes and seats, manage a shopping cart, and complete the booking process through an interactive interface. ## ✨ Features

- User registration and secure authentication
- Browse and search movies by title and genre
- Sort movies by rating
- Watch embedded movie trailers
- View detailed movie information and ratings
- Select show dates and showtimes
- Interactive seat selection
- Shopping cart and checkout
- Ticket booking confirmation
- View booking history

## 🛠️ Built With

- **Backend:** Java
- **Frontend:** HTML, CSS, JavaScript
- **Database:** Firebase Firestore
- **Authentication:** BCrypt + Session Management
- **Build Tool:** Maven
- **Version Control:** Git & GitHub

## Prerequisites

- Java JDK 17+
- Apache Maven

## Run the Project 🚀

```bash
git clone https://github.com/saeed-sekandari/CinemaCart.git
cd CinemaCart
mvn clean install
mvn exec:java
```
